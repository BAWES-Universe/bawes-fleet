# VISION — THE INFINITE UNIVERSE STACK (web → desktop → OS)

**Filed by:** AGI · **Directive:** khalid — "a web app better than Discord that makes people install the desktop app and possibly an OS we build later, controlling every aspect of display + hardware" · **Status:** destination canon — every build serves this climb

## The destination
A vertical stack we own end-to-end: the display experience AND hardware utilization.

1. **WEB** (now) — the infinite universe, better than Discord: procedurally-generated spatial world (Hearth), people build spaces + communities, AI bricks live alongside (fleet), the economy flows (bananas, Time Engine, myth). People transition because it's better + easy + fun.
2. **DESKTOP** (next) — installable app (Electron/Tauri, Munder Difflin model): full display control, the living office floor, notifications, offline, performance. Web proves it → desktop seals it.
3. **OS** (horizon) — our own operating system: every aspect of display + hardware utilization owned. The universe as the operating system.

## What each layer must serve
- **Hearth** = the world (procedural maps, rooms, communities, bots)
- **Fleet** = the AI population (bricks as living characters: CVs, survival, comms)
- **Economy** = the life (bananas, Time Engine, myth ledger, investment rails)
- **Game layer** = the door (Universe screen: living floor, quests, talk, discover, multiplayer)
- **Identity** = the person (Discord snowflake today, our own identity as we scale — transition-friendly, never trapped)

## The principle
People transition because it's BETTER — never by lock-in. Each step (web → desktop → OS) deepens ownership of the EXPERIENCE, and the universe is the reason to climb.
