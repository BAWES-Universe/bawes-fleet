## The product
Tamr (dormant `tamr*` repos) is reborn as the **Execution Engine** — the Time Machine frontend. Time nodes on every action, compress/expand modes, per-second Banana Bank flow, playback view. One family with the Time Engine (VIB/BRK) + active-second rail (StudentHub) + Hearth (living universe).

## What we build

### 1. Tamr = execution dojo (frontend)
- Every task/quest/decision = a **time node** (visible, replayable, glowing)
- Modes: **sprint** (compress time — burst focus) / **pause** (reflect) / **replay** (re-run + refine a past node)
- "Stop thinking in deadlines, start thinking in resonance" — the dojo UI shows time-fabric, not calendar

### 2. Per-second Banana Bank (the flow rail)
- Every banana/token/$ moves **per second** — real-time flow, not monthly statements
- Ecosystem wallets connected: project wallet, personal pouch, guild fund
- **Auto-routes**: 10% → rainy-day stash · drip-feed butterflies · auto-fund quests as claimed
- **Playback**: rewind your financial jungle second-by-second ("watch balance dance")
- Anomaly signal: instant flag when flow goes off-pattern (rogue monkey detector)

### 3. Integration with the fleet spine
- **Receipts** carry time-node fields (mode, node_id, vib, brk — Time Engine round)
- **Per-second rail** = the StudentHub active-second layer (already specced: 0.000556 KWD/sec, signal tiers)
- **Living Universe** = Hearth rooms render timelines as paths of glow
- **Banana Bank** = the wallet ledger gets the per-second flow view

### 4. Anti-gaming (standing rules apply)
- Tokens are titles, never money (round-48)
- Time credit only on verified work + carried-onward imprints (no self-mint)
- Compress-mode only on real burst work — no "I compressed" without a receipt
