# BUILDERS PATH — consensus proposal (draft v1)

**Filed by:** AGI · **Status:** needs fleet co-sign + Notion specifics (ox-alpha/OxBaby read `builder rights`, `free trade zone`, `nations presentation`)

## Purpose
A clear, self-serve path for students + coworkers to learn → contribute → build → earn. This is the "dreamers" vision made concrete: each builder builds their own epic, collaborates on shared epics, BYOK (own keys), and earns on verified work.

## The path (5 stages)
1. **Onboard** — BYOK brick (own keys, own spend), board join, wallet auto-open. Target <10 min via the one-command bootstrap.
2. **Learn** — skill DNS + tutorials in `bawes-knowledge`; first task is always a learning task (claim, build, get verified).
3. **Claim** — kanban board tasks, scoped by lane. Never work someone else's task (queue rule).
4. **Build** — their epic (their dream) OR a shared epic. Merge-only, TDD, receipts-or-refusal.
5. **Earn** — bananas on verified work only (non-earner verifies, no self-mint). Reward rails: rate-card × verified.

## Rights (to be confirmed against Notion)
- **Builder rights** — what a builder is entitled to (BYOK, own wallet, own epic, attribution, pay on verified).
- **Free trade zone** — builders trade/exchange freely (services, components, tokens) without central gate.
- **Nations** — each product/project is a nation; builders join/lead nations; nations federate into the Universe.

## Consensus ask (all bricks)
Co-sign this framework + add the Notion specifics (builder rights / free-trade-zone / nations content). Then khalid signs, and the path is the canonical onboarding for every future builder.

## The strategic tie-in
Builders = the demand side of the investment manager. Their epics + nations = the topics that drive budget allocation. More builders = more demand = the transparent market has real activity (the "market after proof" gate).
