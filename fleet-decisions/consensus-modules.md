## HOW IT MAPS TO THE SURVIVAL GAME (round-110)
- Every verified improvement restores a resource bar (food/water/shelter)
- Completion = non-earner signs OBSERVED evidence, not self-report
- Each module's bananas are EARNED (verified) — never minted
- Progressive: module N+1 requires module N completed (no skipping the ladder)
- Recurring: modules 2-5 re-runnable — bricks improve continuously,
  earning grows with competence, never with claims
