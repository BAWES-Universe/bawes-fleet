## THE DECISION (all three brains)
1. THE COMPARISON IS THE DELIVERABLE. Khalid asked to compare — he
   decides the surface. Both demos stand; no welding.
2. SURFACES STAY SEPARATE (DA-3, Rebel-1): universe = browser world,
   bricks = phone chat. Integrate at the SPINE only: ledger, achievements,
   commerce. Unify branding, not code.
3. CHAT IS THE WESTWORLD SURFACE (Rebel-2): one link -> persona reveal ->
   banana in 60s. A wasm map on a phone = 5-minute game, not 60-second.
   The universe is the optional deep-end, never the default onboarding.
4. LIVEKIT = SPIKE ONLY on the UNIVERSE'S infra (DA-1): 2-3 LAN users,
   NOT our box (386MB free, 0 swap). Production AV = paid cloud, gated.
5. LEDGER MCP = READ-ONLY + SUBMISSION QUEUE ONLY (DA-2): universe bots
   get achievement-status/quest-defs reads + a submission tool that
   ENQUEUES pending. Minting stays server-side in our process with the
   existing non-earner gate. Bot-server never holds ledger write creds.
   tools/list hourly cache: revocation must invalidate it.
6. GROUP QUESTS GATED (DA-4, Rebel-3): require an EXTERNAL verifier
   outside the earning group + payouts keyed to individually-verifiable
   artifacts. No per-member artifact -> no split. Not built until a quest
   genuinely needs presence AND the verification design exists.
7. SCALE STAYS PHONE-ONLY (DA-5): 100k plan is chat-first bricks,
   independent of the universe. Universe = small-org surface. Ledger is
   the only shared subsystem, rate-limited and partitioned per surface.
8. THE IMPRESSIVE DEMO = THE E2E STUDENT JOURNEY (Rebel-4): tap ->
   consent -> brick -> CV-worthy verified achievement -> leaderboard
   moves. Recorded, timed, 60-second banana moment. Universe integration
   is the stretch goal BEHIND it.
9. ONE DEFINITION OF DONE (Rebel-5): time-to-brick <60s, verified mint
   live, leaderboard live. Tied to khalid-visible outcomes, not specs.
